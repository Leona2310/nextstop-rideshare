# NextStop Ride Sharing App

Real-time ride-sharing application built using React Native, Expo and Firebase.

## Features
- Ride booking
- Driver matching
- Shared rides
- OTP verification
- Real-time updates
- Dynamic seat management

## Tech Stack
React Native, Expo, Firebase, Firestore
